# agent-core-demo
web-lambda-agentcore form validation

## This repo includes three parts: 
- frontend web: a simple web page for user input form for backend validation, and a text area for validation result
- backend lambda: expose public urls, receives frontend web request and returns validation result.
- shell folder for provision aws bedrock

- Initialized with react for customization
- feature based folder structure
- Using stylesheet in component
